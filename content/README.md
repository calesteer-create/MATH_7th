# content/ — مصدر حقيقة المحتوى (Content as Code)

**هذه الشجرة هي الموقع المنشور.** كل صفحة على GitHub Pages تُبنى من هنا، لا من
قاعدة البيانات: `npm run build:static` يقرأ `content/*.json` عبر
`src/content/source.ts` وتُثبَّت الصفحات، ثم ينسخ `scripts/build-static.mjs`
صور الدروس المنشورة إلى `media/lessons/…` في المخرَج. ما ليس في هذه الشجرة
(وفي `public/media`) لا يصل إلى طالب. القاعدة المحلية `data/math7.db` غير
متتبعة في git ولا تُنشر إطلاقًا.

- `units/<id>.json` — وحدة واحدة لكل ملف؛ اسم الملف هو الـ `id`.
- `lessons/<id>.json` — درس واحد لكل ملف؛ يضم قائمة `images` مرتبة بصيغة WebP.
- `quizzes/lesson-<id>.json` / `quizzes/unit-<id>.json` — اختبار لكل درس/وحدة (مستقبلي).
- الصور نفسها تحت `public/media/lessons/<id>/` (ويب + `thumbs/`) — نسخ WebP فقط،
  الأصلية تبقى على جهاز المالك. انظر `docs/CONTENT_MODEL.md` للعقد الكامل
  وقواعد التحقق (`npm run content:validate`).

> لا يوجد هنا أي محتوى منهاج. الوحدات والدروس والصور يضيفها مالك المنصة
> من لوحة الإدارة حصرًا. أي مثال مرجعي يظهر في التوثيق أو الاختبارات موسوم
> صراحةً بأنه مثال وليس من المنهاج.

> **قبل إضافة أي درس:** اقرأ المعيار التعليمي الملزم في
> [`docs/LESSON_STANDARD.md`](../docs/LESSON_STANDARD.md) — الالتزام بالكتاب
> السوري، الشرح الموسّع، ودفتر الطالب بوصفه مادة كاملة. هذا المعيار جزء من
> العقد، لا نصيحة اختيارية.
